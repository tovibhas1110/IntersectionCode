### AiM2XL Program: Topology Optimization for the Wire and Arc Additive Manufacturing Process:
**Description:** https://www.tudelft.nl/me/over/afdelingen/materials-science-and-engineering/research/research-programmes/aim2xl

### About code:
MATLAB and Python-based code to produce an additive manufacturing-friendly design with low geometrical complexity.

We quantify geometrical complexity using the stress field generated in the compliance minimization problem.

The popular 88-line code (https://link.springer.com/article/10.1007/s00158-010-0594-7) to generate high-performance, topology-optimized designs is modified to include WAAM-related aspects.
